# 景区游览指南的程序性知识挖掘 (Scenic Guide Mining)

本项目为《数据挖掘》课程探索性实验，旨在从景区官方指南与游客游记中挖掘程序性知识，并构建旅游规划 Agent。

## 目录结构
```text
├── data/               # 存放原始数据与清洗后的数据
├── outputs/            # 存放生成的 JSON、图表等结果
├── src/                # 存放所有 Python 源代码
├── .env                # 存放 API Key（请自行创建）
├── requirements.txt    # 项目依赖包列表
└── README.md           # 项目说明文档
